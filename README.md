## 📋 List of All 7 SQL Queries
1. Retrieve all upcoming football matches belonging to the `Champions League` where the match status is `Available`.
2. Search for all users whose full names start with `Tanvir` or contain the phrase `Haque`.
3. Retrieve all booking records where the payment status is missing and show `Action Required`.
4. Retrieve match booking details along with the user's full name and the match fixture.
5. Display all users and their booking IDs, including users who never bought a ticket.
6. Find all ticket bookings where the total cost is higher than the average booking cost.
7. Retrieve the top 2 most expensive matches after skipping the highest premium match.
